ℹ️ How to Use

Data Types:

  • Reference Data: Game database (agents.json, wengines.json) - auto-loaded from assets/data/
  • User Data: Your personal disc inventory and builds - stored in browser cache

Getting Started:

  1. Reference data loads automatically on app startup - you can start building right away!
  2. Create your builds and add discs through the app
  3. Export your disc inventory regularly for backup
  4. If you update game data files, use "Force Reload Reference Data"

How to Use

  1. Place your JSON data files in src/assets/data/
  2. Expected filenames:
    • agents.json - Agent data
    • wengines.json - W-Engine data
    • discs.json - Disc Drive data
  3. Click "Import All Data" to load everything into IndexedDB
  4. Data persists in your browser's IndexedDB cache
  5. Use export functions to backup your data

Privacy Policy

Data Collection & Storage

ZZZ Optimizer is committed to protecting your privacy. This tool operates entirely within your web browser and does not collect, transmit, or store any personal information on external servers.

Local Storage Only

All data you enter (character builds, disc drives, W-Engines, etc.) is stored locally in your browser using IndexedDB. This data never leaves your device and is only accessible to you.

Limited Server Communication

This application operates entirely locally on your device, with one optional exception: the Enka Network import feature (see below for details). All calculations and optimizations are performed entirely on your device without sending data to servers.

No Tracking or Analytics

We do not use cookies, analytics tools, or any tracking mechanisms. Your usage of this tool is completely private and anonymous.

No User Accounts

This tool does not require user accounts or authentication. You can use it without providing any personal information.

Enka Network Import Feature

This application includes an optional feature to import your character builds from Zenless Zone Zero using your in-game UID (User Identifier). This feature uses external services to fetch publicly available game data.

How It Works

When you use the Enka import feature:

  • Your game UID is sent to our Cloudflare Worker proxy service
  • The proxy forwards your request to Enka Network API
  • Enka Network fetches your public game statistics
  • The data is returned to your browser and stored locally

What Data Is Transmitted

  • Game UID: Your in-game User Identifier (public game data, not personal information)
  • IP Address: Processed by Cloudflare during the request (standard for all web traffic)
  • Character Builds: Public game statistics retrieved from Enka Network

Important: Game UIDs are public identifiers used to display in-game statistics. They do not contain personal information like your email, password, or real name.

Third-Party Services Used

  • Cloudflare Workers: A proxy service that forwards requests to Enka Network. Cloudflare is GDPR compliant and processes data globally through their edge network.
  • Enka Network: A third-party service that provides public game statistics for Zenless Zone Zero. Data is fetched from HoYoverse's public APIs.

Your Privacy & Control

  • This feature is completely optional - you can use the optimizer without importing data
  • No personal information is collected or stored on external servers
  • All imported data is stored locally in your browser only
  • You can delete imported data at any time using the Data Manager
  • Cloudflare complies with GDPR and international privacy regulations

Your Data Control

Since all data is stored locally in your browser, you have complete control over it:

  • Export Your Data: Use the Data Manager to export all your builds and configurations
  • Delete Your Data: Clear your browser's local storage or use the Data Manager to remove specific items
  • Backup Your Data: Export your data regularly to ensure you don't lose your builds if you clear browser data

Third-Party Resources

This application uses game assets and data from publicly available sources. When you visit this site, your browser may load resources from:

  • GitHub Pages: Hosting platform for the application
  • Game asset CDNs: For character images and icons
  • Cloudflare Workers: API proxy service (only used when importing data via Enka)
  • Enka Network: Game statistics API (only used when importing data)

These third-party services may have their own privacy policies. Please refer to their respective websites for more information:

  • Cloudflare Privacy Policy
  • Enka Network

Changes to This Policy

If we make changes to this privacy policy, we will update this page. Since we don't collect any contact information, we cannot notify you directly of changes.
